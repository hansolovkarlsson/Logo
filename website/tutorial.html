How to run these examples

Save a chapter's example into a file, say try.logo, and run bin/logomotive try.logo from this project's root.

A window opens with the turtle's canvas on one side and a history pane on the other. You can also just type commands straight into the entry box at the bottom instead of saving a file first.

1

Turtle basics

Picture a turtle standing at the center of the canvas, facing up. It holds a pen. Tell it to move, and it drags the pen behind it — that trail is your drawing.

FORWARD 100
RIGHT 90
FORWARD 100

FORWARD (or FD for short) moves the turtle that many steps in the direction it's currently facing. RIGHT (RT) turns it clockwise by that many degrees, without moving it. LEFT/LT turns the other way, and BACK/BK moves backward.

Run those three lines and you'll get two sides of a square. Typing the same pair of commands four times is exactly the kind of repetition a computer should be doing for you — the whole subject of the next chapter.

Two more basics worth knowing now:

PENUP
FORWARD 50    ; moves, but draws nothing
PENDOWN
FORWARD 50    ; draws again

PENUP lifts the pen so the turtle can reposition without leaving a line; PENDOWN puts it back down. CLEAR (CS) wipes the canvas and resets the turtle, for a fresh start.

Try it

  • Draw a triangle (three FORWARD/RIGHT 120 pairs).
  • Draw a shape with a gap in one side, using PENUP/PENDOWN.
2

Repetition

REPEAT runs a block of commands a fixed number of times. The block goes in square brackets:

REPEAT 4 [FORWARD 100 RIGHT 90]

That one line draws the whole square from Chapter 1. The general shape is "however many sides, turn 360 / sides degrees each time":

REPEAT 6 [FORWARD 60 RIGHT 360 / 6]     ; a hexagon
REPEAT 100 [FORWARD 2 RIGHT 3.6]        ; enough tiny sides to look like a circle

Inside a REPEAT, the operator REPCOUNT tells you which pass you're currently on, counting from 1:

REPEAT 5 [PRINT REPCOUNT]
1 2 3 4 5

That's useful for shapes that change slightly each time around — a spiral, where each side is a little longer than the last:

REPEAT 20 [FORWARD REPCOUNT * 5 RIGHT 90]

There's also WHILE, for when you don't know the count in advance — it re-checks its condition before every pass:

MAKE "steps 0
WHILE :steps < 4 [
  FORWARD 100
  RIGHT 90
  MAKE "steps :steps + 1
]

And FOR bundles the counter into the loop itself:

FOR [i 1 5] [PRINT :i]
1 2 3 4 5

Try it

  • Draw a five-pointed star with one REPEAT (hint: the turn angle for a star isn't 360 / sides).
  • Use REPCOUNT to draw a spiral of squares, each one bigger than the last.
3

Procedures

Once a shape is worth drawing more than once, give it a name. TO starts a definition, END closes it:

TO square
  REPEAT 4 [FORWARD 100 RIGHT 90]
END

square
square

Now square is a command, exactly like FORWARD or REPEAT. But a square that's always the same size isn't very useful — give the procedure an input:

TO square :size
  REPEAT 4 [FORWARD :size RIGHT 90]
END

square 100
square 30

:size inside the procedure stands for whatever value was passed when it was called. A procedure can take up to eight inputs, and procedures can call each other — that's how you build anything non-trivial:

TO triangle :size
  REPEAT 3 [FORWARD :size RIGHT 120]
END

TO house :size
  square :size
  PENUP FORWARD :size PENDOWN
  triangle :size
END

house 80

Try it

  • Write a polygon :sides :size procedure that draws any regular polygon.
  • Write a procedure that draws a row of houses using a REPEAT around a call to house.
4

Variables & data

MAKE creates or updates a variable; :name reads it back:

MAKE "size 50
FORWARD :size
MAKE "size :size + 10
FORWARD :size
The quote before size in MAKE "size ... means "the word size itself" — MAKE needs to know which variable to set. :size means the opposite: "the value currently stored in size." Mixing these two up is the single most common beginner mistake in Logo.

Numbers work as you'd expect (+ - * /, with *// binding tighter, and parentheses for grouping):

PRINT (2 + 3) * 4
PRINT SQRT 16
PRINT ROUND 3.7
20 4 4

Words and lists are the other two kinds of data. A word is text, written with a leading quote ("hello); a list is a bracketed sequence of things:

MAKE "greeting "hello
MAKE "colors [red green blue]
PRINT :greeting
PRINT :colors
hello red green blue

Try it

  • Store your name in a variable and PRINT SENTENCE "Hello :yourname.
  • Write a procedure that takes a :size input, doubles it into a variable, and draws a square with that doubled size.
5

Conditionals

IF runs a block only when a condition is true:

MAKE "age 10
IF :age >= 13 [PRINT "teenager]

Nothing prints — 10 >= 13 is false. Add an ELSE, or use IFELSE for the same thing spelled differently:

IF :age >= 13 [PRINT "teenager] ELSE [PRINT "kid]
IFELSE :age >= 13 [PRINT "teenager] [PRINT "kid]
kid kid

Comparisons are < > = <= >= <>. Combine conditions with AND/OR/NOT — no parentheses needed, those are for arithmetic only:

IF :age > 0 AND :age < 13 [PRINT "kid]
IF NOT :age = 0 [PRINT "nonzero]

A condition doesn't need a comparison at all — any nonzero number or non-empty word counts as true:

IF WORD? "hi [PRINT "yes-a-word]

WORD? is one of a family of predicates (NUMBER?, LIST?, EMPTY?, MEMBER?, …) that answer yes/no questions about a value.

Try it

  • Write classify :n, printing "negative, "zero, or "positive.
  • Combine IF with REPCOUNT to draw a shape where every other side is a different length.
6

Recursion

A procedure can call itself — Logo's natural replacement for a loop when each step shrinks a problem down to a smaller version of itself:

TO countdown :n
  IF :n = 0 [PRINT "liftoff STOP]
  PRINT :n
  countdown :n - 1
END

countdown 5
5 4 3 2 1 liftoff

Every recursive procedure needs a base case that stops it (here, :n = 0), and a step that moves toward it (:n - 1). Miss either and it calls itself until "Recursion too deep."

STOP ends a procedure with no value; OUTPUT ends it with a value, for a procedure used as an operator:

TO factorial :n
  IF :n = 0 [OUTPUT 1]
  OUTPUT :n * factorial :n - 1
END

PRINT factorial 5
120

Recursion is also how you draw things whose complexity grows with a parameter:

TO spiral :size
  IF :size > 200 [STOP]
  FORWARD :size
  RIGHT 20
  spiral :size + 5
END

spiral 5

Try it

  • Write sum_to :n, outputting 1 + 2 + ... + n recursively.
  • Modify spiral to change pen color each time it recurses (Chapter 8).
7

Lists in depth

A list's elements are pulled apart with FIRST/BUTFIRST/LAST/BUTLAST, counted with COUNT, and indexed with ITEM (1-indexed):

MAKE "fruits [apple banana cherry]
PRINT FIRST :fruits
PRINT BUTFIRST :fruits
PRINT ITEM 2 :fruits
apple banana cherry banana

New lists get built with FPUT/LPUT, SENTENCE (splice into one flat list), or LIST (wrap without flattening):

PRINT FPUT "red [green blue]
PRINT SENTENCE [1 2] [3 4]
PRINT LIST [1 2] [3 4]
red green blue 1 2 3 4 [1 2] [3 4]

Rather than writing your own loop, three higher-order operators handle common patterns directly. Each takes a bracketed template where ? stands for "the current element":

PRINT MAP [WORD ? "!] [apple banana cherry]
PRINT FILTER [NOT ? = "banana] [apple banana cherry]
PRINT REDUCE [SENTENCE ?1 ?2] [1 2 3 4]
apple! banana! cherry! apple cherry 1 2 3 4

MAP transforms every element; FILTER keeps elements where the template is true; REDUCE folds the list to one value (?1 = running result, ?2 = next element). FOREACH is the side-effect version, for when you don't need a new list back.

A word is really a list of characters underneath — FIRST/ITEM/COUNT all work one level deeper on a word too.

Try it

  • Given MAKE "nums [4 8 15 16 23 42], use FILTER to get only the even numbers.
  • Use REDUCE to find the largest number in a list.
8

Color, pen, and multiple turtles

SETPENCOLOR (or SETPC) takes red, green, blue, each 0-255. Each line remembers the color/width it was drawn with:

SETPENCOLOR 255 0 0
FORWARD 80
SETPENCOLOR 0 100 255
RIGHT 90 FORWARD 80

By default there's exactly one turtle. TELL switches which turtle is current — commands always act on whichever turtle is current, creating a fresh one on first use:

TELL 1
SETPENCOLOR 0 200 0
FORWARD 100

TELL 0
RIGHT 90
FORWARD 50

PRINT WHO
PRINT TURTLES
0 2

Each turtle keeps its own independent position, heading, and pen state — switching back with TELL 0 picks up exactly where it left off.

Try it

  • Draw a scene with two turtles in different colors, each drawing a different shape.
  • Draw a rainbow — a REPEAT around a shape, changing SETPENCOLOR a little each pass using REPCOUNT.
9

Input & interactivity

INPUT pauses the script and waits for a typed line, handing it back as a word:

PRINT [What is your name?]
MAKE "name INPUT
PRINT SENTENCE "Hello :name

WAITKEY waits for a single keypress instead, outputting the key's name:

TO drive
  MAKE "key WAITKEY
  IF :key = "Up [FORWARD 20]
  IF :key = "Left [LEFT 15]
  IF :key = "Right [RIGHT 15]
  drive
END

drive

That recurses forever (Chapter 6), each time blocking on the next keypress — a tiny turtle-driving game in six lines.

WAITKEY/INPUT both block. For a background handler that fires without pausing anything else, register one with ONKEY/ONCLICK/ONMOUSEMOVE instead:

TO keyhandler :key
  IF :key = "space [PRINT "jump]
END
ONKEY "keyhandler
Event handlers need the real windowed app to see in action — try this one with bin/logomotive, not by reading alone.

Try it

  • Extend drive to print "bye and stop when the spacebar is pressed.
  • Register an ONCLICK handler that moves the turtle to wherever you click.
10

Capstone: a flower garden

Everything above, combined: procedures, recursion, loops, color, and randomness, to plant a little garden of flowers at random positions.

TO petal :size
  REPEAT 2 [ARC 60 :size RIGHT 60]
END

TO flower :size :petals
  REPEAT :petals [
    SETPENCOLOR (RANDOM 200) + 55 (RANDOM 200) + 55 (RANDOM 200) + 55
    petal :size
    RIGHT 360 / :petals
  ]
END

TO garden :count
  IF :count = 0 [STOP]
  PENUP
  SETXY (RANDOM 300) - 150 (RANDOM 300) - 150
  PENDOWN
  flower 40 8
  garden :count - 1
END

garden 6
PRINT "done-planting

Read it bottom-up if it helps: garden is the entry point, recursive, counting down and planting one flower per call. Each flower is a REPEAT around a petal, choosing a new random color each time. Each petal is two arcs, forming one curved leaf. PENUP/SETXY/PENDOWN jump to a random spot between flowers.

Try it, roughly increasing difficulty

  • Change garden to plant more flowers, or bigger ones.
  • Give flower a :hue_shift input to bias the random colors.
  • Use FOR instead of recursive garden to plant the flowers.
  • Register an ONCLICK handler that plants one new flower wherever you click.

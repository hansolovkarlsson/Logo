What LogoMotive is

Logo turns programming into drawing: a turtle sits on a canvas, and every command — FORWARD, RIGHT, REPEAT — moves it and leaves a trail. It's how a lot of people first learned that code could do something, not just print text. LogoMotive keeps that idea completely intact — the same turtle, the same simple vocabulary — while replacing everything underneath it with a real, modern interpreter: a bytecode compiler and VM, not a line-by-line text scanner, with thousands of levels of real recursion instead of dozens.

On top of the classic language, LogoMotive adds a few things the original never had: independently-scheduled multi-turtle agents, sprite animation, real file I/O, prototype-style objects, and mouse/keyboard event handlers — all while staying a native, no-browser-required desktop app.
